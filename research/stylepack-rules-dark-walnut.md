# Стилевой пак «Тёмный орех» — правила совместимости для каталога

Владелец: Color & Materials Research. Источник палитры: `site/data/palette-dark-walnut.json`.
Обоснование и источники: `research/color-research.md`.

Документ для агента каталога: по нему товар Home Centre **принимается** или **отклоняется** для слота.
Правила проверяемые: цвет — по hex (CIELAB L*, C*, h°), материал — по названию/описанию, размер — по
габаритам (см). Если у товара несколько цветов/материалов — проверяется **доминирующий видимый**
(обивка дивана, столешница стола, полотно штор), остальные — как «детали».

Порядок приоритета, если правила спорят: **глобальные запреты → правила слота → предпочтения**.

---

## 0. Как проверять цвет (скрипт)

hex → CIELAB (D65, sRGB). LRV ≈ Y×100 (цифровое приближение; у производителей краски LRV измерен
спектрофотометром и может отличаться на 2–5 пунктов).

```python
import math
def lab(hexstr):
    h = hexstr.lstrip('#'); c = [int(h[i:i+2], 16) / 255 for i in (0, 2, 4)]
    r, g, b = [x / 12.92 if x <= 0.04045 else ((x + 0.055) / 1.055) ** 2.4 for x in c]
    X = 0.4124*r + 0.3576*g + 0.1805*b; Y = 0.2126*r + 0.7152*g + 0.0722*b; Z = 0.0193*r + 0.1192*g + 0.9505*b
    f = lambda t: t ** (1/3) if t > 0.008856 else 7.787 * t + 16/116
    fx, fy, fz = f(X / 0.95047), f(Y), f(Z / 1.08883)
    L, A, B = 116*fy - 16, 500*(fx - fy), 200*(fy - fz)
    return dict(L=L, a=A, b=B, C=math.hypot(A, B), h=math.degrees(math.atan2(B, A)) % 360, LRV=Y*100)
```

Если `colorHex` у товара нет — берите по фото средний цвет основной поверхности (не блик, не тень)
и округляйте в «тёплую» сторону только при явных признаках (название «sand», «oat», «ivory»).

### Глобально запрещённые цвета

- **Холодные серые** (C* < 5 при h 160–300, L* 30–85) — для любых крупных предметов: диван, кресло, ковёр,
  шторы, покрывало, изголовье. Пример отказа: `#A7A9A8`, «light grey», «charcoal grey» в обивке.
- **Голубовато-белые и оптический белый** (L* > 94 и h 180–300, либо `#FFFFFF` с оптическим отбеливателем)
  — в текстиле крупнее подушки.
- **Красно-оранжевые и «рыжие» породы**: вишня, махагон, тик, акация, «golden oak», рыжая сосна,
  палисандр (h < 48° при C* > 25, или C* > 30 при L* 40–55). Пример отказа: `#8B4A30`, `#6F2F20`, `#9E6B3C`.
- **Венге / эспрессо / почти чёрное дерево** (L* < 18) и **серо-белёное дерево** (C* < 9, «grey wash»,
  «white wash», «rustic grey»). Пример отказа: `#2E231D`, `#8E8478`.
- **Насыщенные «чистые» цвета и пастели**: красный, кобальт, изумруд, фуксия, лимонный, неон, мятный,
  детский розовый/голубой, бирюза (C* > 45 вне A2/A3).
- **Металлы**: хром, полированный никель/сталь, медь, розовое золото, зеркальное «золото», «antique silver».
- **Отделки**: высокий глянец (лак, акрил, глянцевая плитка/МДФ), зеркальные фасады, стекло+хром,
  искусственная кожа с блеском, атлас/сатин с блеском, глиттер, пайетки, «crushed velvet».
- **Узоры**: крупный высококонтрастный (чёрно-белый геометрический, зигзаг, леопард, крупные цветы,
  «мраморный» принт), логотипы, надписи.

## 2. Глобальные правила пака

1. **60/30/10.** Оболочка ≈60% (стены `#ECE7DE`, потолок `#F2EFE8`, пол дуб `#C6A984`, фасады `#D6CFBF`);
   текстиль N1/N2 + орех W1 ≈30%; акценты (A1–A4, L1, M1, K1, S1) ≤10% видимой площади.
2. **Тона дерева: максимум 2** — W1 орех (вся мебель) + W2 светлый дуб (пол). Натуральные волокна F1
   (ротанг, сетка, джут) — как «текстура», ≤ 5% площади, не считаются третьим деревом. Дуб/ясень в мебели
   допускается только в мелочах (рамка, поднос, ножки торшера) — не в крупной мебели.
3. **Допуск ореха.** Все ореховые предметы — W1 и **ΔE76 ≤ 10 от `#553C2C`**, одинаковый подтон (h 50–68°).
   Если один предмет заметно рыжее/краснее остальных (h < 50°) — отклонить, даже если он «орех» по названию.
   Шпон/плёнка допустимы при матовой отделке и правдоподобной текстуре (без повторяющегося принта).
4. **Тёмные массы.** «Тёмная масса» = предмет с L* < 40 и фронтальной площадью > 0,5 м². На студию —
   **не больше 4** (обычно: ТВ-тумба, кровать-рама, обеденный стол, журнальный стол). Две тёмные массы
   не стоят вплотную без светлой прослойки (ковёр, текстиль, камень, светлая стена). Орех — 10–15%
   площади в любом кадре, никогда не > 20%.
5. **Крупные поверхности светлые.** Диван, покрывало/одеяло, ковёр, шторы: L* ≥ 70 (LRV ≥ 40), семейства
   N1/N2 (ковёр допускает светлый N3, L* ≥ 65).
6. **Акцентный бюджет.** Не больше **двух семейств акцентного цвета** на студию: базово **A1 олива + A2
   терракота** (они «родственны» через жёлтую/охристую основу). A3 охра и A4 чернильный — только внутри
   wall_art или одного предмета decor_set. L1 коньяк — **один** тип предмета (кресло **или** сиденья
   стульев **или** кожаные детали лампы/подноса).
7. **Металлы: максимум 2.** M1 латунь (сатин/шлиф/состаренная) — доминирующий декоративный металл
   (≈70% металлических деталей). K1 матовый чёрный — только тонкими линиями (окно уже чёрное: каркас
   торшера, ножки, рамы). Внутри одной функции — один металл: обе прикроватные лампы одинаковы,
   все ручки/фурнитура мебели — одного металла.
8. **Блеск.** Только матовые/шелковисто-матовые поверхности. Глянец ≤ 0,3 м² в кадре (стекло ваз,
   глазурь мелкой керамики — можно).
9. **Текстура как цвет.** В нейтральной схеме фактура обязательна: минимум 3 разные фактуры в зоне
   гостиной (например, рогожка дивана + шерстяной ковёр + лён штор + букле/кожа кресла). Букле — **не
   больше одного предмета** на студию.
10. **Узор.** Не больше одного крупного узорчатого текстиля на студию (ковёр **или** покрывало **или**
    шторы), узор низкоконтрастный (ΔL* внутри узора ≤ 25), мелкий/средний масштаб.
11. **Statement-предметы.** Не больше **3** на студию и **1** на зону (гостиная / спальня / обеденная).
    Statement = скульптурная форма, крупный рисунок, яркий акцентный цвет, крупная латунь.
12. **Свет.** Все лампы 2700 K (допуск 2700–3000 K, разброс между лампами ≤ 300 K), CRI ≥ 90 (R9 ≥ 50).
    Абажуры — лён/хлопок/бумага/опаловое стекло; прозрачные абажуры с голой лампой — нет.
13. **Габариты** не превышают `max` слота из `layout-studio.json`; проходы ≥ 75 см; низкая мебель
    (спинка дивана ≤ 85 см, ТВ-тумба ≤ 60 см) — чтобы линия окна и стен читалась.

## 3. Правила по слотам

Формат: **цвет** (семейства) · **материалы/отделки** · **запрещено** · **размер** (см, для студии 38 м²) ·
**statement**. «★» — предпочтительный вариант по умолчанию.

### sofa — диван (max 240 × 105 × 100)
- **Цвет:** N2 ★ (овсяный, песок, лён) или N1 (молочный); светлый N3 (L* ≥ 65) — только при светлом ковре N1.
- **Материалы:** рогожка, лён/льняная смесь, шенилл с матовым ворсом, плотный хлопок; букле — допустимо,
  если это единственный букле-предмет. Ножки — орех W1 или скрытый цоколь; тонкие латунные M1 — допустимо.
- **Запрещено:** любая кожа и экокожа (крупная тёмная масса), серый, тёмный (L* < 65), бархат с блеском,
  капитоне/честерфилд, хромированные ножки, контрастный кант, узор.
- **Размер:** ширина 200–230 ★ (3-местный), глубина 85–100, спинка 75–85, высота сиденья 42–46.
  Угловой — только если правая ветка ≤ 160 и не перекрывает проход к окну.
- **Statement:** нет (диван — спокойный фон гостиной).

### armchair — кресло (max 95 × 95 × 105)
- **Цвет:** L1 коньяк ★ (кожа на ореховом каркасе, mid-century) **или** N1/N2 (букле/рогожка) **или**
  A1 олива (матовый бархат/рогожка). Каркас/ножки — W1 орех или ротанг/сетка F1.
- **Материалы:** анилиновая/полуанилиновая кожа (матовая), букле, рогожка, лён, матовый бархат (только A1);
  каркас массив/шпон ореха; сиденье/спинка из венской сетки — допустимо.
- **Запрещено:** чёрная/белая/серая кожа, глянцевая экокожа, металлический каркас (кроме тонкого M1),
  кресло-мешок, яркие цвета, дублирование материала дивана один-в-один (кресло должно контрастировать
  с диваном фактурой или цветом).
- **Размер:** ширина 65–85, глубина 70–90, высота ≤ 95 (высокое «ушастое» — только если ≤ 105 и
  силуэт лёгкий). Ножки видимые (пол под креслом виден) ★.
- **Statement:** да, может быть statement гостиной (тогда журнальный стол — спокойный).

### cushions — подушки (комплект на диван)
- **Цвет:** 2–4 шт.; база N1/N2 (1–2 шт.) + акцент A1 и/или A2 (1–2 шт.); допустима 1 подушка A3 охра
  **или** L1 коньяк (кожа/замша). Не более 2 акцентных семейств в комплекте.
- **Материалы:** лён, хлопок-рогожка, шерсть, букле (если диван не букле), матовый бархат A1/A2,
  вышивка тон-в-тон, тонкая полоска.
- **Запрещено:** серые, чёрно-белые, пайетки/металлик, атлас, мех ярких цветов, крупная геометрия,
  надписи, кисти/помпоны контрастного цвета.
- **Размер:** 45×45 или 50×50 + 1 поясничная 30×50; не больше 4 шт. на 3-местный диван.
- **Statement:** нет.

### coffee_table — журнальный стол (max 130 × 90 × 50)
- **Цвет:** W1 орех ★ или S1 травертин (столешница); комбинация орех + травертин — допустимо.
- **Материалы:** массив/шпон ореха (матовый), травертин хонингованный, тёплый мрамор хонингованный;
  круглая/овальная/«галька»-форма ★ (обтекаемость в узкой комнате 4,6 м).
- **Запрещено:** стекло + хром, чёрный мрамор, зелёный мрамор, белый глянец, металлическая сетка,
  «индустриальный» металл, рыжее дерево, состаренное «реклаймд» дерево.
- **Размер:** круглый Ø 80–100 ★ или овал 110–130 × 60–75; высота 35–45; ≈ 2/3 длины дивана по
  ширине не обязательно — приоритет проходу ≥ 45 см до дивана и ≥ 75 см до ТВ-зоны.
- **Statement:** допустимо (скульптурный травертин), если кресло спокойное.

### side_table — приставной столик (max 55 × 55 × 65)
- **Цвет:** **другой материал, чем у журнального стола**: если журнальный W1 → столик S1 травертин,
  M1 латунь, C1 керамика или F1 ротанг; если журнальный S1 → столик W1 орех.
- **Материалы:** травертин, латунь сатин, матовая керамика, орех, ротанг.
- **Запрещено:** стекло+хром, акрил, глянец, чёрный металл массивный (допустим только тонкий каркас).
- **Размер:** Ø 35–50, высота 45–60 (на уровень подлокотника дивана ±5 см).
- **Statement:** нет.

### tv_unit — ТВ-тумба (max 190 × 50 × 65)
- **Цвет:** W1 орех ★; фасады — орех, рифлёный орех, вставки из сетки F1; ручки M1 латунь или без ручек.
- **Материалы:** шпон/массив ореха, матовый лак/масло; столешница может быть травертин S1.
- **Запрещено:** глянец любого цвета, белый/чёрный корпус, стекло, цветная LED-подсветка,
  массивный «комод до пола» без ножек при глубине > 45 (тёмная глыба), рыжий/красный орех.
- **Размер:** ширина 160–190 (≥ 1,1 × ширины ТВ 65″ ≈ 145 см), глубина 35–45, высота 45–60;
  на ножках/цоколе с теневым зазором или подвесная ★ (виден пол — меньше «массы»).
- **Statement:** нет (это одна из ≤4 тёмных масс).

### bed — кровать (max 190 × 225 × 125)
- **Цвет:** рама W1 орех ★; либо мягкое изголовье N1/N2 + ореховая рама/ножки. Полностью мягкая
  кровать в N2 — допустимо (тогда орех — в тумбах).
- **Материалы:** шпон/массив ореха, рогожка/лён/букле на изголовье, вставка из сетки F1 в изголовье.
- **Запрещено:** серый/тёмный текстиль изголовья, капитоне со стразами, кожа, металлическая рама,
  глянец, «замок»-изголовье выше 125, кровать-подиум на всю ширину стены.
- **Размер:** под матрас 150–160 × 200 (ширина рамы ≤ 190); king 180 — **нет** (не влезает с тумбами);
  изголовье 90–115 от пола; низкий профиль (боковина ≤ 35) ★.
- **Statement:** допустимо (изголовье — statement спальни), тогда wall_art над кроватью спокойный.

### mattress — матрас
- **Цвет:** N1 (белый тёплый/молочный чехол); видимая боковина — N1/N2.
- **Материалы:** любой, лишь бы чехол был светлый и матовый.
- **Запрещено:** чёрная/серая/цветная боковина, контрастный кант, глянцевая ткань.
- **Размер:** 150 × 200 или 160 × 200, высота 20–30.
- **Statement:** нет.

### bedding — постель
- **Цвет:** база N1 ★ (тёплый белый, слоновая кость) — пододеяльник и простыни; второй слой N2
  (овсяный плед/покрывало) **и** один акцент A1 или A2 (плед, наволочка). Покрывало — L* ≥ 70.
- **Материалы:** стираный лён ★, хлопок-перкаль/сатин матовый, вафельный хлопок, вязаный плед.
- **Запрещено:** оптический белый (голубит днём), серый, тёмно-синий, чёрный, крупный принт,
  шёлк/атлас с блеском, металлик, сразу A1 + A2 + A3.
- **Размер:** под матрас 150–160 × 200; покрывало свисает 20–30 см.
- **Statement:** нет.

### nightstand — прикроватная тумба (группа: 2 шт., одна модель)
- **Цвет:** W1 орех ★ (как кровать, ΔE ≤ 6 к раме) или контраст: S1 травертин / C1 керамика, если
  кровать полностью ореховая и массивная.
- **Материалы:** шпон/массив ореха, травертин, сетка F1 во фронте; ручки M1 латунь.
- **Запрещено:** зеркальные, глянцевые, стекло, белые/серые, металлические.
- **Размер:** ширина 40–50, глубина 35–45, высота 50–60 (≈ уровень матраса ±5 см); на ножках ★.
- **Statement:** нет.

### dining_table — обеденный стол (max 100 × 100 × 78)
- **Цвет:** W1 орех ★ (столешница); или столешница S1 травертин/тёплый мрамор + основание W1.
- **Материалы:** шпон/массив ореха, травертин, хонингованный мрамор; опора — центральная тумба/«пьедестал» ★.
- **Запрещено:** стекло, белый глянец, чёрный металл массивный, мрамор Неро/зелёный, рыжее дерево,
  прямоугольник > 100 в длину (не влезает).
- **Размер:** круглый Ø 90–100 ★ (на 2–4 человека), высота 74–77.
- **Statement:** допустимо (форма опоры), тогда подвес — спокойный.

### dining_chair — обеденный стул (группа: 2 шт., одна модель)
- **Цвет:** каркас W1 орех + сиденье N2 (рогожка) ★, или L1 коньяк (кожа), или F1 сетка/ротанг;
  полностью мягкий стул N1/N2 на ореховых ножках — допустимо.
- **Материалы:** орех, рогожка, кожа L1 (если L1 не использован в кресле), венская сетка, плетение.
- **Запрещено:** прозрачный пластик, хромированная трубка, чёрный пластик, «тюльпан» белый глянец,
  бархат ярких цветов, коньяк при коньячном кресле (L1 — один тип предмета).
- **Размер:** ширина 45–55, глубина 50–58, высота спинки 75–85; без подлокотников или с низкими

- **Statement:** нет.

### floor_lamp — торшер (max 50 × 50 × 180)
- **Цвет:** основание/стойка M1 латунь или K1 матовый чёрный (тонкая) или W1 орех (тренога);
  абажур N1/N2.
- **Материалы:** лён, хлопок, плиссированная бумага, рисовая бумага, опаловое стекло; латунь сатин.
- **Запрещено:** дуговые торшеры с выносом > 50 см, хром, цветные абажуры, прозрачное стекло с
  голой лампой, «прожектор-тренога» чёрный металл, LED-ленты RGB.
- **Размер:** высота 150–175, абажур Ø 35–50; основание ≤ Ø 35.
- **Свет:** 2700 K, CRI ≥ 90, диммер ★.
- **Statement:** допустимо как скульптурный (бумажный) — тогда кресло спокойное.

### table_lamp — настольная лампа (группа: 2 шт., одна модель)
- **Цвет:** основание C1 (кремовая/песочная/терракотовая/оливковая матовая глазурь) ★, S1 травертин,
  W1 орех или M1 латунь; абажур N1/N2; «грибок» из опалового стекла + латунь — допустимо.

- **Запрещено:** хром, кристаллы/хрусталь, цветное стекло, глянцевая керамика ярких цветов, прозрачные

- **Statement:** нет.

### pendant_lamp — подвес над обеденным столом (max 70 × 70 × 100)
- **Цвет:** N1/N2 (лён, бумага) ★, F1 (ротанг/плетение), опал + M1 латунь; K1 — только тонкий каркас.
- **Материалы:** рисовая бумага, лён, плетение, опаловое стекло, латунь сатин.
- **Запрещено:** хрустальные люстры, хром, цветное/дымчатое синее стекло, «индустриальный» чёрный
  колпак, кластеры из многих ламп с открытыми колбами.
- **Размер:** Ø 40–60 для стола Ø 100 (≈ ½–⅔ стола) ★; низ на высоте 70–85 см над столешницей.
- **Свет:** 2700 K, CRI ≥ 90, рассеянный (не точечный вниз).
- **Statement:** допустимо (это может быть statement обеденной зоны).

### rug — ковёр (max 300 × 220)
- **Цвет:** N1/N2 ★, светлый N3 (L* ≥ 65); **ковёр светлее ореха журнального стола минимум на 30 пунктов LRV** (≈ порог контраста BS 8300)

  тонкая линия A1/A2/L1, низкий контраст.

  каймой или фактурой), берберская стрижка.
- **Запрещено:** серый, чёрно-белый, тёмный (L* < 65), яркий персидский/восточный с красным/синим

- **Размер:** 200 × 300 ★ (или 200 × 290); минимум 160 × 230 — только если передние ножки дивана

- **Statement:** только если остальное спокойно; по умолчанию — нет.

### curtains — шторы (max 390 × 15 × 285, окно в пол)

## 4. Быстрые отказы (чек-лист для каталога)

Отклонить товар, если выполняется **любое**:
1. Основной цвет — холодный серый, голубовато-белый, чёрный (кроме K1-деталей), насыщенный «чистый» цвет.
2. Дерево не W1 (рыжее, красное, венге, белёное) или ΔE > 10 от `#553C2C`.
3. Металл — хром/никель/медь/розовое золото/зеркальное золото.
4. Глянцевая крупная поверхность.
5. Габарит больше `max` слота.
6. Предмет добавляет пятую «тёмную массу» или третий тон дерева.
7. Предмет добавляет третье акцентное семейство или второй тип коньячной кожи.
8. Крупный высококонтрастный узор.

Пограничные случаи — помечать `review` в `research/catalog-sourcing.md` и не включать в `options`.
